# Supervisor Brief

This file can be used to prepare the first discussion with the supervisor.

## Current Understanding of the Topic

The thesis investigates the use of robotic systems in lithium-ion battery cell manufacturing. The focus is on identifying suitable robotic applications along the production value chain and evaluating them from technical and economic perspectives.

The preliminary scope includes electrode manufacturing, cell assembly, cell finishing, testing, and intralogistics. Relevant robotic systems include industrial robots, collaborative robots, mobile robots, and vision-guided systems.

## Preliminary Research Questions

1. Which battery cell production steps are most suitable for robotic automation?
2. Which process requirements make robotic implementation difficult?
3. Which use cases have the highest potential regarding quality, cost, efficiency, and scalability?
4. How can selected use cases be developed into realistic application scenarios?
5. What implementation recommendations can be derived for industrial deployment?

## First Candidate Use Cases

| Use Case | Reason for Interest |
| --- | --- |
| Formation and testing tray handling | Repetitive, high-volume, strong logistics relevance |
| AMR/AGV dry room intralogistics | Reduces manual transport and supports scalable material flow |
| Vision-guided inspection and robot loading | Strong connection to quality improvement and data integration |
| Cell assembly handling for stacking or housing insertion | High potential, but technically demanding |

## Questions for Supervisor

1. Should the thesis focus on one cell format, such as pouch, prismatic, or cylindrical cells?
2. Should pack assembly and recycling be excluded completely?
3. Is the expected result mainly a literature-based evaluation, or should it include expert interviews or case studies?
4. Should the economic evaluation be qualitative, semi-quantitative, or based on a cost model?
5. Are there PEM/eLab use cases, production lines, or internal sources that should guide the focus?
