# Glossary CN-EN / 中英术语表

This file is a learning glossary. The goal is not perfect academic wording, but quick understanding.

这个文件是学习用术语表。目标不是一上来写得很学术，而是先能看懂、能讨论、能读文献。

| English Term | 中文 | Simple Meaning / 人话理解 |
| --- | --- | --- |
| Lithium-ion battery cell manufacturing | 锂离子电芯制造 | 把原材料、电极、隔膜、电解液、壳体等制造成单个合格电芯的过程。 |
| Cell | 电芯 | 最基本的储能单元。电池包里面通常有很多电芯。 |
| Module | 模组 | 多个电芯组合成的中间单元。 |
| Pack | 电池包 | 电动车或储能系统里使用的完整电池系统，包含电芯/模组、结构件、冷却、BMS 等。 |
| Electrode manufacturing | 电极制造 | 制造正极片和负极片的阶段。 |
| Cell assembly | 电芯装配 | 把正极、负极、隔膜、电解液、壳体等组装成电芯。 |
| Cell finishing | 电芯后处理 | 电芯装好后进行化成、老化、测试、分选等。 |
| Mixing | 混料 | 把粉末、粘结剂、导电剂、溶剂等混成浆料。 |
| Coating | 涂布 | 把浆料均匀涂到铜箔或铝箔上。 |
| Drying | 干燥 | 去除涂布后的溶剂或水分。 |
| Calendering | 辊压 | 用辊子把电极压实、压薄，使厚度和孔隙率符合要求。 |
| Slitting | 分切 | 把宽电极卷切成较窄的目标宽度。 |
| Vacuum drying | 真空干燥 | 在真空环境下进一步去除水分。 |
| Notching / cutting | 模切/裁切 | 把电极片切成需要的形状。 |
| Stacking | 叠片 | 正极、隔膜、负极一层层叠起来。 |
| Winding | 卷绕 | 正极、隔膜、负极像卷起来一样形成卷芯。 |
| Tab welding | 极耳焊接 | 把电芯内部导电连接片焊接起来。 |
| Housing insertion | 入壳 | 把电芯内部结构放进壳体或软包膜中。 |
| Electrolyte filling | 注液 | 向电芯中注入电解液。 |
| Sealing | 封口 | 把电芯密封，避免泄漏和污染。 |
| Formation | 化成 | 电芯第一次受控充放电，相当于激活和建立稳定界面。 |
| Aging | 老化 | 电芯静置一段时间，观察性能是否稳定。 |
| Testing | 测试 | 测量容量、电压、内阻、安全等指标。 |
| Grading / sorting | 分选 | 根据性能和质量把电芯分等级。 |
| Dry room | 干房 | 低湿度生产环境，用于保护怕水的电池材料和工序。 |
| Industrial robot | 工业机器人 | 传统高速、高精度机械臂，适合重复性任务。 |
| Collaborative robot / Cobot | 协作机器人 | 更适合与人接近工作的机械臂，常用于试制线和柔性工位。 |
| AGV | 自动导引车 | 通常沿固定路线运输物料的小车。 |
| AMR | 自主移动机器人 | 可以自主导航和避障的移动机器人。 |
| Vision-guided robotics | 视觉引导机器人 | 机器人配合相机和图像处理，用于定位、检测和纠偏。 |
| Intralogistics | 厂内物流 | 工厂内部原材料、半成品、托盘、电芯等的流动。 |
| Traceability | 可追溯性 | 能记录每个产品经过的材料、设备、工艺参数和测试结果。 |
| MES | 制造执行系统 | 管理生产执行、设备数据、产品追溯的工厂信息系统。 |
| Cycle time | 节拍 | 完成一个生产循环或处理一个产品所需的时间。 |
| Delicate material handling | 精细/脆弱材料搬运 | 对薄、软、易损材料进行温和、精确的搬运。 |
| Contamination control | 污染控制 | 避免灰尘、水分、油污、颗粒等进入产品或工艺。 |
| ESD protection | 防静电保护 | 避免静电放电影响质量或安全。 |
| Current collector | 集流体 | 把电极产生或接收的电子导入外部电路；负极常用铜箔，正极常用铝箔。 |
| Binder | 粘结剂 | 把活性材料、导电剂和集流体粘结在一起，维持电极机械完整性。 |
| Active material | 活性材料 | 电极中真正储存和释放锂离子的材料。 |
| Conductive additive | 导电剂 | 提高电极内部电子导电性的添加材料。 |
| PVDF | 聚偏二氟乙烯 | 常见正极粘结剂，通常配合 NMP 溶剂使用。 |
| NMP | N-甲基吡咯烷酮 | 正极浆料中常用于溶解 PVDF 的溶剂。 |
| CMC | 羧甲基纤维素 | 负极加工中常用的水系粘结剂。 |
| SBR | 丁苯橡胶 | 常与 CMC 搭配用于负极的粘结剂/乳化剂。 |
| NMC | 镍锰钴酸锂 | 常见层状正极体系，兼顾能量密度、功率和寿命。 |
| NCA | 镍钴铝酸锂 | 使用镍、钴、铝的高能量正极体系。 |
| LFP | 磷酸铁锂 | 以安全、稳定和循环寿命著称的正极材料。 |
| LCO | 钴酸锂 | 经典钴酸锂正极材料，常用于消费电子。 |
| LMO | 锰酸锂 | 锰酸锂正极，常与尖晶石结构相关。 |
| Thermal runaway | 热失控 | 热量加速产生并可能导致起火或爆炸的危险失效模式。 |
| Short circuit | 短路 | 正负极之间发生非预期电连接，可能带来安全风险。 |
| Energy density | 能量密度 | 单位质量或单位体积能储存多少能量，常影响电动车续航。 |
| Power density | 功率密度 | 单位质量或体积能多快输出能量，影响加速、快充等性能。 |
| Self-discharge | 自放电 | 电池即使不使用也会逐渐损失电量。 |
| Cyclability | 循环性能 | 电池经历多次充放电后维持性能的能力。 |
| Intercalation | 嵌入/脱嵌 | 锂离子进入或离开电极材料晶格结构的过程。 |
| Specific capacity | 比容量 | 单位质量材料能够储存的电荷量。 |
| Operating voltage | 工作电压 | 电芯充放电工作时的电压水平。 |

## One-Sentence Map / 一句话地图

Battery cell manufacturing first makes electrode sheets, then assembles them into cells, and finally activates, tests, and sorts the cells.

电芯制造先做电极片，再装配成电芯，最后化成、测试、分选。
