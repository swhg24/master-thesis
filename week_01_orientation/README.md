# Week 01 Orientation

Goal of this week: turn the thesis topic into a clear research map.

By the end of week 01, we want four working outputs:

1. Scope and research questions
2. Battery cell manufacturing process chain
3. Process requirement table
4. Robotics application matrix
5. Chinese-English glossary for key terms

These files are not final thesis text. They are working notes that will later become the basis for the literature review, methodology, and case selection.
