模块 2 — Day 2 核心

Connector Handling 放大：从看见到插入的每一步

这是 Day 2 最重要的内容。以下把 S5（Connector Handling）和 S10（Connector Removal）拆成 sub-step 级别。每一步标注：物理含义、负责系统、证据来源和当前未知。

插入阶段（INSERTION PHASE）

#Step物理含义负责系统证据关键 Unknown
I1 Perceive / Locate
感知与定位		 用视觉或传感器找到连接器的空间位置和姿态，以及 Pack 上目标接口的位置和姿态。 Robot (vision) 小墨披露
Wang 2024 综述		 使用何种传感器（2D/3D相机、力传感器）；接口可见性；遮挡与照明条件
I2 Approach
接近		 机器人末端执行器从安全位置移动到连接器附近，同时避免与线束、Pack 或工装发生碰撞。 Robot (motion) 运动规划 接近路径的约束；线束在接近过程中是否已被支撑
I3 Grasp Connector / Support Harness
抓取连接器或支撑线束		 夹爪或其他末端执行器抓取连接器本体。若线束长且柔软，可能需要另一只手或机构支撑线束，防止重力或弯曲导致连接器姿态不可控。 Robot (end effector) 小墨披露
Gebauer 2024		 连接器几何；抓取点；是否需要双臂；夹爪设计
I4 Pre-align
预对准		 将连接器移动到接口前方大致正确的位置和姿态，使连接器轴线与接口轴线基本重合。这一步通常由视觉引导完成。 Robot (vision + motion) Wang 2025
KUKA 案例		 允许的初始位姿偏差范围；视觉精度
I5 Approach Mating Interface
接近对接接口		 连接器从预对准位置向接口方向移动，但尚未发生物理接触。这是从"自由空间运动"到"接触运动"的过渡。 Robot (motion) 运动规划 接近速度；是否在接近过程中实时调整姿态
I6 First Contact
首次接触		 连接器的某个部分（导向销、外壳边缘、端子尖端）首次与接口发生物理接触。此时可能出现单点接触、多点接触或边缘接触，力/力矩信号开始出现。 Robot (force sensing) Wang 2025 CATL 现场是否使用力传感器；接触检测策略
I7 Fine Alignment
精细对准		 利用接触力/力矩反馈或几何约束（如导向槽、倒角）将连接器姿态调整到与接口完全对齐。这是插接中最容易出错的阶段——可能发生卡滞（jamming）或楔紧（wedging）。 Robot (compliance + force) Wang 2025
Gebauer 2024		 目标连接器是否有导向结构；柔顺策略（主动/被动）
I8 Insertion
插入		 连接器沿轴线方向推入接口，端子完成电气接触。插入力可能因摩擦、端子数量和装配公差而变化。此阶段需要力/位置混合控制，不能仅靠位置控制。 Robot (force-position hybrid) Wang 2025
Gebauer 2024		 插入力/拔出力范围；插入深度；端子数量
I9 Lock / Seating / CPA
锁止与就位		 连接器到达最终就位位置后，执行锁止动作（如推动 CPA 杆、扣合 latch 或旋转 locking ring）。KUKA 邻近案例使用弹簧机构、气缸和终点传感器控制 CPA 锁止。 Robot (end effector) KUKA 案例 目标连接器是否有 CPA/锁止机构；锁止是否需要额外动作
I10 Connection Confirmation
连接确认		 验证连接器已完全就位且锁止完成。可能的判据：力传感器检测到就位力峰值、终点开关触发、电气连续性检测、或视觉再次确认。千寻披露"检查线束连接状态"。 Robot + PLC 小墨披露 具体判据（力/位置/电信号/视觉）；确认失败的恢复策略

#Step物理含义负责系统证据关键 Unknown
R1 Safe-to-Disconnect Permission
安全断开许可		 测试完成 → 去能量 → PLC 确认安全状态 → 向机器人发出断开许可。这是 Day 2 重点强调的"process state → robot permission"。 PLC / Safety 系统推导 CATL 现场安全状态机；断开许可的判据
R2 Unlock / Release

拔出		 沿轴线方向将连接器从接口中拔出。拔出力可能因端子摩擦、真空吸附或热膨胀而不同于插入力。拔出后需确保连接器和端子无损伤。 Robot (force-position) 小墨披露 拔出力范围；拔出后是否检查连接器/接口状态

脱离接口		 连接器完全脱离接口区域，避免与 Pack 或其他设备发生碰撞。此时测试设备与 Pack 之间已无物理连接。 Robot (motion) 运动规划 脱离后的安全位置

线束归位		 将连接器和线束放回存放位置，恢复为下一次连接可用的状态。若线束在操作中发生缠绕或变形，可能需要整理。 Robot (manipulation) 小墨披露 归位位置；线束是否需要在归位时整理

模块 3

三个必须区分清楚的概念

这三个概念区分是 Day 2 最重要的学习收获。过去容易把它们混在一起，导致后续分析失去精度。

1 Alignment（对准）≠ Insertion（插入）
Alignment 对准

连接器姿态大体满足插入条件。视觉可以告诉你"连接器在接口前方，轴线大致重合"。

视觉解决"我在哪里"。

Insertion 插入

连接器沿轴线推入，发生接触、摩擦、可能的卡滞。需要力/力矩反馈来检测和纠正 misalignment。

力控解决"我怎样不卡住地进去"。

为什么必须区分：视觉对准了 ≠ 插接问题就解决了。连接器可能因为 in-hand pose error（Gebauer 2024 的核心发现）、接口公差、线束拉力或摩擦而卡滞。把两者混为一谈，就会错误地认为"有视觉 = 能插好"。

2 Physical Insertion（物理插入）≠ Successful Connection（连接成功）
Physical Insertion 物理插入

连接器本体已经推入接口。端子可能已经接触，也可能没有完全就位。

"插进去了"只是机械动作完成。

Successful Connection 连接成功

需要额外确认：fully seated? locked? CPA engaged? electrical continuity? state signal returned?

"连接成功"需要系统状态确认。

为什么必须区分：如果只做插入不做确认，可能出现"插进去但没锁止→测试中脱落"或"端子接触不良→测试结果错误"。对于 Pack EoL 高压测试，连接不可靠的后果比普通插头装配严重得多。这就是 Connection Confirmation（I10）是独立步骤的原因。

3 Test Complete（测试完成）≠ Robot Can Pull（机器人可以拔线）
Test Complete 测试完成

EoL 测试设备完成了所有测试项，产生了测试结果。但 Pack 可能仍处于带电状态，或测试设备尚未切换到安全模式。

只是电气测量结束。

Robot Can Pull 可以拔线

需要 PLC 确认：测试设备已去能量、Pack 接口处于安全状态、工作区域安全 → 发出 Safe-to-Disconnect Permission → 机器人才允许执行拔出动作。

需要 process state → robot permission。

为什么必须区分：这是这个 case 相比普通插头装配更有 battery-manufacturing relevance 的地方。机器人虽然只负责物理 manipulation，却受到 electrical process state 的约束。如果不理解这一点，就会把"机器人拔插头"当成一个纯机械动作，忽略 EoL 的安全互锁要求。

学习要点：这三个区分构成了 Day 3 需求分析的基础。Day 3 会问"为什么这个任务不能简单等同于插一个插头？"——答案就藏在这三个区分里：因为视觉对准不够（需要力控插入），因为插入不等于成功（需要连接确认），因为测试结束不等于可以拔线（需要安全互锁）。

如何读这张图

  • 横向读：每个阶段，五个主体各自在做什么。注意 CONNECT 阶段 Robot 和 PLC 同时活跃——Robot 做物理操作，PLC 做安全门控。
  • 纵向读：每个主体在整个周期中的责任范围。Robot 只在 CONNECT 和 DISCONNECT 阶段有任务，其余阶段等待或被 PLC 约束。

关键系统交互点

  • Robot ↔ PLC：Safe-to-connect 和 Safe-to-disconnect 是 PLC 对 Robot 的硬约束。Robot 不能自行决定何时插入或拔出。
  • Robot ↔ Tester：Robot 建立物理连接后，Tester 才能执行测试。两者不直接通信，通过 PLC 中介。
  • PLC ↔ Tester：Test enable 和 De-energize 确认是 PLC 和 Tester 之间的安全握手。

模块 5

4 个关键 Failure Modes（不是 FMEA）

Day 2 只选对后续机器人能力分析最有意义的 4 个 failure modes。不要扩成 BMS fault、thermal runaway 或完整 EoL defect taxonomy。

F1 — Connector not found / pose uncertain

连接器不在预期位置，或视觉系统无法可靠确定其空间姿态。可能原因：线束变形导致连接器位置偏移、来料位置变化（小墨披露明确提到）、遮挡或光照变化。

影响：Perception / Localization 对应步骤：I1 Day 3 能力需求：视觉鲁棒性、pose estimation、多模态感知
F2 — Harness deformation causes bad approach

线束因重力、弯曲刚度或之前操作的影响而变形，导致连接器姿态偏离预期，或抓取后连接器在手中发生不可预测的位姿变化（Gebauer 2024 的 in-hand pose uncertainty）。

影响：Deformable-object handling / Grasp 对应步骤：I2, I3 Day 3 能力需求：DLO 状态估计、双臂支撑、自适应抓取
F3 — Misalignment / jamming during insertion

连接器在插入过程中因初始姿态偏差、接口公差或接触力分布不均而发生卡滞（jamming）或楔紧（wedging）。这是 Wang 2025 论文的核心研究对象。

影响：Compliance / Force sensing / Corrective motion 对应步骤：I6, I7, I8 Day 3 能力需求：力/力矩感知、柔顺控制、搜索与恢复策略
F4 — Connection not confirmed

连接器已推入，但未完全就位、锁止未完成或电气连续性检测失败。此时若直接进入测试，可能造成测试结果错误或高压安全隐患。

影响：State confirmation / Integration 对应步骤：I9, I10 Day 3 能力需求：多模态确认、异常检测、与 PLC 的握手协议
不放大的内容：BMS fault、battery thermal runaway、HV isolation algorithm、完整 EoL defect taxonomy。这些会把研究方向重新拉回 battery testing 本身，而不是 robot task。

KUKA 邻近案例的边界：KUKA/Liebherr/KOSTAL 案例是 Pack assembly 中的永久连接，不是 EoL 临时测试连接。但二者共享"柔性电缆 + 电连接器 + 位姿偏差 + 接触插入 + 连接确认"的技术结构，因此是有效的邻近工业基线。Day 2 引用它解释 I9（Lock/CPA）和"固定工业机器人也能做柔性 connector insertion"。

以下记录了 Day 2 学习完成后，学生与导师之间的五轮带教式问答。每道题包含：学生原始回答、导师纠正/补充、以及最终评价。保留此记录用于日后复盘。

Q1 为什么 EoL tester 和 robot 不是同一个系统角色？
学生回答

在我看来，eol tester 是电气装置方面，负责对电池的工艺标准做质量检测，robot 只是物理层面，辅助电气装置以及检验设备的一个自动化角色。两者之间应该通过厂间 plc 来协调。

导师点评

方向正确。补充两点：(1) Robot 不是泛泛的"辅助角色"，它只做一件事——建立和解除物理测试连接（CONNECT + DISCONNECT），测试进行时它不参与；(2) 关键交互链：Robot 插好 → PLC 确认 → Tester 才能开始测试 → Tester 测完 → 去能量 → PLC 确认 → Robot 才能拔。每一步顺序依赖，不是同时各干各的。

Q2 解释 approach、first contact、alignment、insertion、connection confirmation 五者的差异
学生回答

approch 是机器人视觉定位后接近那个目标位置，first contact 是第一次物理交互？然后 alignment 是对齐对准位置，精定位？insertion 是插入，开始执行动作，connect confirmation 应该是机器人跟 plc 交互，向他发送确认请求。

导师点评

方向对，但五处需要修正：

  1. Approach ≠ 视觉定位。 视觉定位是 I1（Perceive/Locate），Approach 是 I2——视觉已告知位置，机器人把末端执行器从安全位置移过去，纯运动规划阶段，尚未接触任何物体。
  2. First Contact 核心在于控制策略切换：在此之前是自由空间运动（位置控制），在此之后进入接触运动（需要力/力矩反馈）。
  3. Alignment 漏了讲义最关键的两层拆分：I4 Pre-align（视觉引导，粗对准）和 I7 Fine Alignment（接触力反馈，精对准）。两者解决不同问题，依赖不同传感器。
  4. Insertion 不只是"开始执行动作"：连接器沿轴线推入，端子接触，摩擦力、公差共同决定插入力，可能出现卡滞或楔紧。需要力/位置混合控制，不能只靠位置控制。
  5. Connection Confirmation 不只是"跟 PLC 交互"：首先是机器人自己要验证（完全就位？锁止啮合？电气连续性？），验证通过后才把确认信号发给 PLC。学生只说了通信后半段，漏了物理验证前半段。

核心要点：这五步对应三种不同的控制模式——自由空间运动（Approach）→ 接触力引导（First Contact + Fine Alignment）→ 力/位置混合（Insertion）→ 状态确认（Confirmation）。不能跳过任何一步，因为每一步依赖不同的传感器和控制策略。

Q3 为什么"机器人把 connector 插进去了"还不意味着整个连接任务结束？
学生回答

因为不管是通讯层面还是物理接触层面，插进去不代表连接任务结束，插入之后需要力反馈等力传感器反馈？然后还要发给 plc 来确认，应该是 robot 做物理层面的确认，然后 plc 是通讯接受确认结果？失败的后果应该是任务放弃？

导师点评

方向对，三处补充：

  1. 确认什么？不止力反馈。讲义列出的判据包括：力传感器检测就位力峰值、终点开关触发、电气连续性检测、视觉再次确认。力反馈只是其中一种。
  2. 谁确认？Robot 是确认的执行者（I10 负责方：Robot + PLC），PLC 是确认的门控者——Robot 汇报"连好了"，PLC 判断"是否允许 Tester 启动"。
  3. 失败后果不是"任务放弃"。对于 Pack EoL 高压测试：锁止未完成 → 测试中脱落 → 高压电弧风险；端子接触不良 → 测试结果错误 → Pass/Fail 误判；电气连续性未建立 → 无法通信 → 产线停摆。这就是 Connection Confirmation 被列为独立步骤 I10 的原因。
Q4 为什么 test finished 之后 robot 不能默认立即拔线？
学生回答

因为 tester 能量还不一定释放完，要 plc 来决定拔，因为这会影响电池的工艺质量？

导师点评

核心点"能量没释放完"抓到了，但"影响电池工艺质量"不够精确。真正风险是两层：

  1. 安全风险：Pack 可能仍处于高压带电状态，直接拔线 = 操作人员/设备暴露于高压风险。
  2. 过程状态风险（讲义核心论点）：测试设备完成了测量，但尚未完成"去能量 + 安全状态确认"状态转换。若此时 Robot 拔线，PLC 安全互锁链被打破，可能导致：测试数据未完整写入 MES → 记录缺失；安全回路异常断开 → 触发故障停机 → 影响整线节拍。

核心区分：Robot 只负责物理 manipulation，但受 electrical process state 约束。这不是纯机械的"插拔插头"任务——如果是普通插头装配，测完就拔没问题。但 Pack EoL 测试中，Robot 的拔线动作必须等 PLC 的 Safe-to-Disconnect 信号。这个"process state → robot permission"的依赖关系，是让这个 case 具有 battery-manufacturing 特殊性的关键。

Q5 Insertion jamming 是 perception/motion/force-contact/tester 哪类问题？
学生回答

contact 问题吧，视觉对准了但是力传导，以及深度位置都有可能会导致这个卡滞？

导师点评

正确，核心是 force/contact 问题。但"视觉对准了为什么还会卡"需要更精确的三个原因：

  1. In-hand pose error（Gebauer 2024 核心发现）：视觉告诉你连接器在空间中的位置，但抓取之后连接器在夹爪里的实际姿态可能和视觉估计不一样。视觉对准了 ≠ 连接器在手里是准的。
  2. 线束拉力：连接器不是刚体，连着柔性线束。线束重力、弯曲刚度、缠绕都会给连接器施加不可预测的力/力矩，在插入过程中改变姿态。
  3. 接触力分布不均 + 接口公差：即使初始姿态正确，插入过程中端子与接口的接触力分布不均、摩擦系数差异、装配公差累积，都可能导致楔紧或卡滞。

这就是 Alignment ≠ Insertion 的核心含义：视觉解决"我在哪里"（几何问题），力控解决"我怎样不卡住地进去"（接触力学问题）。两个问题用不同传感器、不同控制策略。把"有视觉 = 能插好"当作理所当然，就是在掩盖这个任务真正的技术难度。
