# Week 02: Robotics Evidence Chain / 第二周：机器人应用证据链

## This Week's Question / 本周核心问题

How can we move from battery manufacturing knowledge to evidence-based analysis of robotic applications?

如何从电池制造知识，走向有证据支撑的机器人应用分析？

## Learning Order / 学习顺序

1. `day1_process_problem_map_learning_guide.html`
   - Learn to read each process as: objective -> risk -> task -> robotic role.
   - 学会把每道工序读成：目标 -> 风险 -> 任务 -> 机器人角色。

## Week 02 Direction / 第二周方向

This week is for building understanding and an evidence chain, not for prematurely fixing final use-case rankings or ROI values.

本周用于建立理解和证据链，不急于确定最终案例排名或 ROI 数值。
